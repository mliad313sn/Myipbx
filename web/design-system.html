Appliance design system

tokens and primitives for the console. no network, no framework, no build step.

What this page is for

Every colour, size, depth and duration the console may use is named once in css/tokens.css, and every primitive built on those names lives in css/components.css. This page shows all of them, in each theme and each density, so that a change can be judged against everything it affects rather than against the one screen it was made for.

Three rules are enforced rather than encouraged. Nothing is fetched from a network, because these appliances are frequently air gapped. No component writes a colour of its own, because a literal colour cannot follow a theme. No state is carried by colour alone: every status below has a mark and a word, and every health lamp has a shape.

Themes

The operating system's own preference is the default signal, and an explicit choice overrides it in both directions — a light console on a dark desktop and a dark console on a light one. The three panels below are drawn at the same time by the same rules, each holding a different theme, which is the quickest way to see a token that has been given a value in one theme and forgotten in another.

The dark theme is not the light one inverted. Its canvas is a dark slate rather than black, its surfaces rise above that canvas instead of sinking below it, and its status colours are chosen again from scratch, because the light theme's greens and reds are dark inks that disappear against a dark panel. The high contrast theme keeps every border and widens the focus ring rather than removing either, and drops shadows entirely, since a soft edge is the thing that theme exists to avoid.

Colour

The swatches read their values from the page as it is drawn, so changing the theme above changes what is reported here. A name describes the job rather than the appearance; that is what lets three themes disagree about the value without a single rule having to know.

The headline figure is set in equal width lining figures. The quantity itself is spelled — an operator reads twelve active calls, never a digit — but an identifier keeps its digits, and an address, a port or a version is what those tabular figures are for.

Spacing

A four pixel baseline. Each step is named by the value it carries, because a name that says what it measures outlives a name that says where it is used.

motion

Four durations, all short. This is an operations console: a transition long enough to be admired sits between an operator and the state of a telephone system. An operating system asking for reduced motion takes all four to nothing, and the two components that animate rather than transition are handled where they are defined.

depth

One ordered scale, so that two unrelated parts of the console can never argue about which of them is on top.

Density

Comfortable is the default, and holds every control to a target of at least forty-four pixels, because the console is used standing at a rack as often as sitting at a desk. Compact gives that up knowingly, for the operator watching many rows at once on a fixed screen. Only measurements move; no colour and no component rule knows which density is in force.

Buttons

Four intents and three sizes. Danger is bordered rather than filled: a wall of red buttons stops being a warning, and the word on the button is what says which service it interrupts. Every one of them shows the keyboard ring outside its own edge, so it stays visible on a filled button as well as a transparent one.

choices

A validation message is a sentence saying what to do, marked and coloured and placed under the field that caused it. The colour is the last of those three, not the first. A required field says the word rather than wearing an asterisk, and a switch says on or off by where its knob sits and by the mark printed in its track.

Status

Eight system conditions and the telephony vocabulary beside them, all drawn by one badge. The mark comes from a value every variant must set, so a variant that forgets one draws nothing and is noticed immediately rather than shipping as a colour-only signal.

Waiting

Both of these say the same thing — the appliance has been asked and has not answered yet — and both need a word beside them, because a shape that turns is not a sentence. The spinner is for an action an operator started; the skeleton is for a region that will fill in on its own.

compiling the interface drivers against the running kernel
applying the ruleset

Under reduced motion the skeleton stops shimmering and simply sits there, since the shimmer only decorates. The spinner keeps turning, slowly: it is the only sign that a privileged operation is still running, and a frozen spinner reads as a hung console.
